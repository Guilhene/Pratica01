2. REQUISITOS DO FRONTEND (React Native)
Implemente as seguintes melhorias no template do aplicativo:
- *Autenticação:* Crie uma tela que infrome o neme de usuario com validação de acesso.
- *Boas-vindas:* Exiba uma mensagem de boas-vindas com o nome do usuário autenticado na tela principal.
- *Filtros:* Na pagina recentes informa as despesas mais recentes de 7 dias.
- *Visualização de Dados:* Implemente gráficos (ex: gráfico de pizza) na aba de resumo para visualizar as despesas/receitas por categoria.
- *Gestão de Transações:* Permita a edição e exclusão de transações acionadas por um "toque longo" (long press) que abre um Modal de opções.
- *Gestão de Categorias:* Adapte o frontend para consumir e criar novas categorias customizadas direto do banco de dados (além das 5 fixas).
- *Integração:* Crie um Client HTTP (ex: Axios ou Fetch) para consumir os endpoints criados no Backend.
